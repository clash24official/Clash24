# Clash24 Website

A responsive, original esports-style website inspired by the purple/orange mobile UI shown in the reference images, but not a copy.

## Add your Android APK
1. Create this folder:
   app/
2. Put your APK inside it with this exact filename:
   Clash24.apk
3. Keep the existing Download APK button in `index.html`.

## Run locally
Open `index.html` in a browser.

For best local testing, use a simple local server, for example:
python -m http.server 8000

Then open:
http://localhost:8000

## Publish
Upload all files to your hosting provider. A static host such as GitHub Pages, Netlify, Vercel, or similar can host the website.

Important:
- Replace placeholder branding/assets with your own logo and tournament artwork.
- The template does not implement deposits, wagering, withdrawals, or prize-money transactions.
- Check applicable laws, platform rules, and Free Fire/Garena tournament policies before operating any paid-entry tournament service.
